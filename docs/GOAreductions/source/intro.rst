Introduction
============

This document describes the reduced data in the Gemini Observatory Archive.
Most of this data is reduced using the DRAGONS pipeline. DRAGONS is invoked
automatically by GOA by various mechanisms in order to provide Science Quality
reduced data to the Gemini user community in a timely manner.

While DRAGONS records the history and provenance of a reduced data product in
the reduced file itself, higher level documentation of the reduction strategies
used and the conditions which cause GOA to trigger DRAGONS reduction is
essential information in making scientific use of the reduced data, and we aim
to document that here.
